These are reproducible steps through the useful research path, followed by the unsuccessful branches. They are a curated reconstruction of the research, **not a verbatim log of every search query**. Research was performed on 8 November 2026.

**Start from the image**

1. Open [the supplied image](inputs/carousel.png) at full resolution. Record visible identifiers before searching: pink pig, turquoise saddle, orange lower blanket, red ribbon and two gold bells, curly tail; dark cat and feathered ostrich behind; green spiral on a white support; engraved street scene on the wall. Distinguish the object from the surrounding museum installation.
2. Search images and ordinary web results with `carousel pig museum`, `carousel pig cat ostrich camel museum`, and `Williamsburg museum carousel pig cat ostrich camel`. Follow the Williamsburg leads. Searches also surfaced pigs at the Museum of Fine Arts Boston and Mingei; do not adopt them solely because they have a similar species or maker. Match the painted details and the installation.
3. Search `"Sidewalks to Rooftops" carousel`. Open Colonial Williamsburg's [exhibition page](https://www.colonialwilliamsburg.org/discover/historic-area/art-museums-of-colonial-williamsburg/exhibitions/sidewalks-to-rooftops-outdoor-folk-art/). Scroll past the long navigation to the actual exhibition text and object pictures. Open the cat and camel images. Compare the cat and striped column with the input.
4. Open the Williamsburg Tourism Council's [museum listing](https://www.visitwilliamsburg.com/listing/abby-aldrich-rockefeller-folk-art-museum/1139/). Its carousel installation photograph is also discoverable in image search. The direct image URL and a saved copy are in the download manifest. Compare the wider composition, including the wall engraving. The listing's textual extraction was incomplete; the photograph is the useful part of this lead.
5. Open the museum's [collections introduction](https://emuseum.colonialwilliamsburg.org/groups). Check how it describes the relationship between the Art Museums of Colonial Williamsburg and the two constituent museums. Use the official museum website to verify the city. Do not confuse the carousel's eventual operating park with the city containing this museum display.

**Reproduce the local source checks**

Run these as separate commands from a terminal with ordinary public internet access. Existing source files are reused by the download script; it records failures instead of silently treating them as saved pages.

```bash
python3 ./scripts/download_sources.py
```

Generate searchable text and full-page source renders (requires Poppler's `pdftotext` and `pdftoppm`):

```bash
python3 ./scripts/build_evidence.py
```

Search the historic inventory:

```bash
rg -n -i -C 5 'Lead Horse|Animals in Storage|acorn|Norton|aluminum' ./sources/pullen-1976-national-register.txt
```

Check the cost-related branch:

```bash
rg -n -i -C 4 '1975|1976|60,000|330,798|208,000|Norton|sanding' ./sources/nca-guide-008-pullen-restoration-news.txt
```

Verify download hashes against the manifest:

```bash
python3 - <<'PY'
from pathlib import Path
import hashlib
import json
root = Path('./sources')
entries = json.loads((root / 'download-manifest.json').read_text())
for entry in entries:
    if 'sha256' not in entry:
        continue
    actual = hashlib.sha256((root / entry['file']).read_bytes()).hexdigest()
    assert actual == entry['sha256'], entry['file']
print('All saved source hashes match.')
PY
```
