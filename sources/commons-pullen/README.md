# Wikimedia Commons source photographs

Photographs **Pullen Park Carousel 01.JPG–48.JPG** by **[Hudacko](https://commons.wikimedia.org/wiki/User:Hudacko)**, dated **21 September 2012**, downloaded as the 1280-pixel previews supplied by Wikimedia Commons. Licensed **[Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/)**. Downloaded JPEG bytes are preserved unchanged. No endorsement by the photographer is implied.

Individual source pages, download URLs, retrieval dates, and SHA-256 hashes are in [manifest.json](manifest.json). Public image metadata, including attribution and licensing, are in [index.json](index.json) and continuation [index-2.json](index-2.json). Request URLs and hashes are saved alongside them.

The category index covers 69 files; 48 numbered photographs were downloaded for layout comparison. The focal proof uses 25, 24, 23, and 22. These are source photographs, not images created by the researcher.

Some source descriptions mistakenly repeat text about a reindeer. The research relies on visible carvings and layout, not those descriptions. See [the position analysis](../../Q6_POSITION.md).
